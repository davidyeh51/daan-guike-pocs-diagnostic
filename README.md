## 📌 核心診斷重點與事實（Facts）

- **分析數據規模**：2026/06/20 – 09/17 共 90 天，7 台在線逆變器逐日採集數據（累計 309,824 kWh）。
- **🔴 P1 INV-013 致命容量缺損**：
  - 發電僅為同儕標竿的 54%，9/5–9/9 停機 5 天，9/10 復機後跌至 45%。
  - 90 天累計發電損失達 **24,645 kWh**（占全場 7.4%，營收損失約 NT$ 11.1 萬元）。
  - 推論為直流側約 45–55% 容量未併入（組串或 MPPT 斷路），絕緣阻抗（Riso）劣化引發保護跳脫，**具高度高壓直流電弧火災隱患**。
- **🟠 P2 INV-001 局部衰退**：
  - 相對同儕比值自 89.9% 降至 89.2%，9/4 起階躍跌至 88.3%，推論為 1 處組件旁路二極體導通、局部熱斑或積污遮蔽。
- **🟡 P3 A/B 組容量與發電倒掛**：
  - A 組平台登錄容量較大（119.9 vs 113.2 kWp），實發電量反而倒掛落後 5%，需比對竣工圖與現場組件清冊。
- **🟡 P4 監控日射計失能**：
  - `insolation` 與 `pr` 欄位全部為 0；且存在 6 台跳號設備。傳統 SCADA 監控處於盲區失守狀態。

## 🛡️ AI Agent 如何協助投資者改善電廠資產

1. **7×24 小時動態同儕差分引擎**：無需日射計即可過濾天候波動，在比值偏離 5% 且持續 48hr 即推播工單，將傳統 90 天沉默損失壓至 3 天收斂，避損率達 **96.7%**。
2. **財務損失即時貨幣化**：每日即時換算 kWh 缺口至現金流（NTD），對接躉購費率，讓投資人清晰掌握 IRR 影響。
3. **IEC 62446-1 自動化標準工單**：整合熱像儀、Voc/Isc 與 1000V 兆歐表（Riso ≥ 1MΩ）安全 SOP，並強制遵循 1500V DC 帶電防弧與 LOTO 上鎖掛牌。
4. **全生命週期數位健康病歷**：為案場建立透明、可審計的設備歷程，修復後每年增益 **NT$ 44.3 萬元**，提升專案 IRR +0.42%，確保二級市場交易估值溢價。
